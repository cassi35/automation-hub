# Diretrizes de Contribuição & Workflow

## Fluxo pra adicionar uma automação

1. Backlog: nome, objetivo, tempo estimado, subtarefas
2. Branch: `feat/<nome-automacao>`
3. Commit: conventional commits (feat:, fix:, docs:)
4. Criar pacote em `packages/<nome>`
5. Preencher README com `docs/automation-template.md`
6. (Opcional) Criar issue correspondente no Jira
