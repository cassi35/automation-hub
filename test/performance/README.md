Esse tipo de teste é chamado principalmente de:

Performance Testing (Teste de Performance)

É o termo geral para medir:

tempo de execução;
latência;
consumo de CPU;
memória;
throughput;
comportamento sob carga.

Dentro dele existem alguns tipos mais específicos:

1. Benchmark Test (Benchmarking)

- medir quanto tempo uma operação leva e comparar resultados.

2. Regression Performance Test (Teste de regressão de performance)

- garantir que uma mudança de código não deixou o sistema mais lento.

3. Load Testing (Teste de carga)

- "quantas execuções consigo rodar ao mesmo tempo?"

4. Stress Testing

- É parecido com carga, mas até quebrar.

5. Profiling
   Não é exatamente teste.

É descobrir onde o tempo está sendo gasto.
